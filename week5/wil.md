# 5주차 WIL 2026/05/08

이번 AI 스터디 5주차에서는 결정트리, 검증 세트, 교차검증, 그리고 랜덤 포레스트에 대해 학습하였다.

먼저 와인 데이터셋을 사용하여 alcohol, sugar, pH 값을 입력 데이터로 사용하고, 와인의 종류를 정답 데이터로 사용하는 분류 모델을 실습하였다. pandas를 사용하여 csv 파일을 불러오고, train_test_split을 통해 Train set과 Test set으로 데이터를 분리하였다.

또한 StandardScaler를 사용하여 데이터 전처리를 진행하였다. 이후 LogisticRegression 모델을 사용해 와인을 분류해보았는데, Train score와 Test score가 모두 낮게 나오는 과소적합 현상을 확인할 수 있었다.

다음으로 DecisionTreeClassifier를 사용하여 결정트리 모델을 학습하였다. 결정트리는 스무고개처럼 데이터를 특정 기준으로 계속 나누어 분류하는 알고리즘이라는 점을 배웠다. 특히 plot_tree()를 사용해 결정트리 구조를 시각화해보면서, 어떤 기준으로 데이터가 나뉘는지 직접 확인할 수 있었다.

또한 gini 불순도의 개념도 학습하였다. 한 노드 안에 서로 다른 클래스가 얼마나 섞여 있는지를 의미하며, 모델은 gini 값이 낮아지는 방향으로 데이터를 분할한다는 점을 이해할 수 있었다.

하지만 기본 결정트리 모델은 Train score는 매우 높고 Test score는 상대적으로 낮게 나와 과대적합이 발생하였다. 이를 해결하기 위해 max_depth 값을 제한하는 가지치기를 적용하였다. max_depth를 줄이면 트리의 복잡도가 감소하고, 과대적합을 방지할 수 있다는 점을 확인하였다.

과제에서는 max_depth 값을 1, 3, 5, 10으로 직접 변경하며 Train score, Validation score, Test score를 비교해보았다. 이를 통해 max_depth가 너무 작으면 과소적합이 발생하고, 너무 크면 과대적합이 발생할 수 있다는 점을 직접 확인할 수 있었다.

또한 Validation set의 필요성도 학습하였다. Test set을 반복해서 사용하면 모델이 Test 데이터에 맞춰져 버리는 문제가 발생할 수 있기 때문에, Train 데이터 내부에서 Validation set을 따로 분리하여 모델 성능을 비교하는 방법을 배웠다.

이후 교차검증을 실습하였다. cross_validate()를 사용하여 데이터를 여러 Fold로 나누고, 각 Fold마다 Validation score를 계산하였다. 과제에서는 K=3, K=5, K=10으로 나누어 Fold score와 Mean score를 비교하였다. 이를 통해 데이터를 한 번만 나누는 것보다 여러 번 나누어 검증하는 방식이 더 안정적인 성능 평가를 가능하게 한다는 점을 이해할 수 있었다.

마지막으로 RandomForestClassifier를 사용한 랜덤 포레스트도 실습하였다. 여러 개의 결정트리를 생성하여 다수결 방식으로 결과를 예측하는 앙상블기법이라는 점을 배웠다. 또한 Bootstrap 샘플링과 OOB Score 개념도 학습하였으며, 여러 트리를 사용하는 방식이 단일 결정트리보다 더 안정적인 성능을 제공할 수 있다는 점을 확인할 수 있었다.

이번 실습을 통해 머신러닝에서는 단순히 모델 하나를 사용하는 것보다, 과대적합을 방지하고 모델의 일반화 성능을 높이기 위한 Validation set, 교차검증, 하이퍼파라미터 조정, 앙상블 기법 등이 매우 중요하다는 점을 배울 수 있었다.
