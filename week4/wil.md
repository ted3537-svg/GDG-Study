# 4주차 WIL 2026/05/7

이번 AI 스터디 4주차에서는 로지스틱 회귀와 SGDClassifier를 이용한 학습 방법에 대해 실습하였다.

먼저 fish_csv_data 데이터를 이용하여 물고기의 무게, 길이, 대각선 길이, 높이, 너비를 입력 데이터로 사용하고, 물고기 종류를 타깃 데이터로 사용하였다. 이후 train_test_split을 사용하여 훈련 세트와 테스트 세트로 데이터를 분리하였다.

또한 StandardScaler를 사용하여 데이터 표준화를 진행하였다. 각 feature들의 값 범위 차이가 크기 때문에 스케일링이 필요하다는 점을 다시 확인할 수 있었고, 평균과 표준편차를 기준으로 데이터를 정규화하는 방법을 학습하였다.

이후 KNeighborsClassifier와 LogisticRegression을 사용하여 물고기 분류를 수행하였다. 특히 LogisticRegression은 단순히 분류 결과만 출력하는 것이 아니라 predict_proba()를 이용해 각 물고기 종류에 대한 확률까지 출력할 수 있다는 점이 인상적이었다. 이번 과제에서는 새로운 물고기 데이터셋을 직접 입력하여 어떤 물고기로 예측되는지 확인하고, 각 물고기별 확률 값도 출력해보았다.

또한 SGDClassifier를 이용하여 확률적 경사 하강법 방식의 학습도 실습하였다. partial_fit()을 사용하여 한 epoch씩 반복 학습을 진행하고, 매 epoch마다 train score와 test score를 기록하였다. 이후 matplotlib를 사용하여 epoch에 따른 정확도 변화를 그래프로 시각화하였다.

그래프를 통해 epoch가 너무 적으면 충분히 학습되지 않는 과소적합 상태가 나타나고, epoch가 너무 많아질 경우 train score는 계속 증가하지만 test score는 감소하는 과대적합 현상이 발생할 수 있다는 점을 확인할 수 있었다.

또한 loss='hinge' 옵션을 사용하여 선형 SVM 방식으로 SGDClassifier를 학습시켜보았고, epoch=10 모델과 더 큰 epoch 값을 사용한 모델의 정확도를 비교해보았다. 이를 통해 적절한 epoch 값을 선택하는 것이 모델 성능에 매우 중요하다는 것을 이해할 수 있었다.

이번 실습을 통해 머신러닝에서는 단순히 모델을 사용하는 것뿐만 아니라, 데이터 전처리, 확률 출력, epoch 조절, 과소적합과 과대적합의 균형 등을 함께 고려해야 한다는 점을 배울 수 있었다.
